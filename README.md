# Carnet de voyage — Loire & Beauval

Site statique à une page pour le voyage du 7 au 11 septembre (Voiron → Val de Loire → Beauval).

## Déployer sur GitHub Pages

1. Créez un nouveau dépôt sur GitHub (public), par exemple `carnet-loire`.
2. Ajoutez **tous les fichiers de ce dossier** à la racine du dépôt : `index.html`, `favicon.ico`, `favicon-192.png`, `favicon-512.png`, `apple-touch-icon.png` (glisser-déposer sur la page GitHub, ou `git add` / `git commit` / `git push` si vous utilisez la ligne de commande).
3. Allez dans **Settings** (Paramètres) du dépôt → **Pages** (dans le menu de gauche).
4. Sous **Source**, choisissez la branche `main` et le dossier `/ (root)`, puis cliquez sur **Save**.
5. Attendez 1 à 2 minutes : GitHub affiche l'URL de votre site, du type :
   `https://votre-nom-utilisateur.github.io/carnet-loire/`
6. Ouvrez cette adresse sur votre téléphone et ajoutez-la à l'écran d'accueil (Safari → icône de partage → "Sur l'écran d'accueil") pour un accès en un tap, comme une vraie application.

Le site fonctionne entièrement hors-ligne une fois chargé une première fois dans le navigateur (aucune donnée dynamique, aucun serveur nécessaire).
